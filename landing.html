How it works

From download to finished deck.

Everything is native PowerPoint, so there's no plug-in to install and no advanced design skills required.

  1. Install the fonts

    Install Manrope and Inter, both free from Google Fonts, before editing.

  2. Pick a layout

    Duplicate a slide, or start from a Vertex master with Home › New Slide.

  3. Replace the content

    Click any text to type. Headlines should state the message, not the topic.

  4. Change the colours

    Design › Variants › Colors. Every shape and chart follows the theme.

  5. Edit the charts

    Right-click a chart › Edit Data. Charts re-colour with the theme.

  6. Swap the icons

    Icons are SVG. Use Graphics Format › Fill to recolour, or Convert to Shape.

FAQ

Good questions.

Everything you need to know before you buy.

What software do I need?

Microsoft PowerPoint. The template is a standard 16:9 .pptx file. Install the two free fonts it uses, Manrope and Inter from Google Fonts, before you start editing.

Are the charts really editable?

Yes. All 37 are native PowerPoint charts with an embedded worksheet. Right-click a chart › Edit Data, change the numbers, and the chart updates.

Can I change the colours to match my brand?

Yes. Every shape, text run and chart series uses a theme colour, so Design › Variants › Colors recolours the entire deck at once.

Does it include photos?

No. The design is built around typography, data, icons and geometric shapes, so there are no stock photos to replace or license.

What about the numbers and names on the slides?

They're sample content for a fictional company, there to show how each layout reads with real-looking data. Replace them with your own.

Can I edit the icons?

Yes. The 90 icons are embedded as SVG with a PNG fallback. Recolour them with Graphics Format › Fill, or use Convert to Shape.

How do I get the file?

Checkout is handled by Gumroad. Once your purchase is complete, the .pptx is available to download straight away.
