FAQ

Good questions

Are the charts images?

No. All 42 are native PowerPoint charts. Right-click any chart and choose Edit Data to type or paste your own numbers.

Do I need to install fonts?

No. The template uses Georgia and Arial, which ship with Windows, macOS and Office, so it looks the same on every machine.

Can I use my brand colours?

Yes. Change the theme colours in Design › Variants › Colors and shapes and text update. Charts can be recoloured with Chart Design › Change Colors.

Are there photos to replace?

None. The design uses typography, charts, shapes and vector icons only, so there’s nothing to license or swap out.

What’s the sample content?

Realistic figures for a fictional company, Halden Group, so you can see how each slide reads. Replace them with your own.
